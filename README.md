# PM English

Статическое приложение для изучения профессионального английского через карьерные кейсы пяти треков. Работает на GitHub Pages; проверка заданий происходит в браузере, прогресс сохраняется локально и, после входа, через существующую Firebase-интеграцию.

**Сначала:** [архитектура и полный каталог файлов](АРХИТЕКТУРА.md), [свежие изменения](Изменения.md), [правила работы](AGENTS.md).

## Запуск

Нужны Python 3 и современный браузер. В корне репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть <http://127.0.0.1:8000/>. Обязательной сборки приложения нет. `index.html` — только оболочка, стили находятся в `assets/styles/`, поведение — в `src/`, материалы — в `data/`.

## Разработка и проверки

Для инструментов нужны Node.js 20+ и npm:

```sh
npm ci
npm run check
npm test
npm run format:check
```

`npm run dev` запускает тот же Python-сервер. `npm run format` форматирует поддерживаемый исходный код; авторские данные и сгенерированные материалы не переформатируются этой командой.

Браузерным тестам нужны Playwright и Chromium. Используется `/usr/bin/chromium` либо переменная `CHROMIUM_PATH`. При необходимости установить браузер через `npx playwright install chromium`; его путь можно получить командой `node -p "require('playwright').chromium.executablePath()"` и передать через `CHROMIUM_PATH`. HTTP-сервер приложения должен работать во время тестов.

```sh
npm run test:browser:career
npm run test:browser:additional
npm run test:browser:product
npm run test:browser:project
npm run test:browser:ba
npm run test:browser:ui
npm run test:browser:parity
```

Назначение наборов, переменные окружения и ограничения — в [tests/README.md](tests/README.md).

## Где менять код

- Основной кейс: источник в `content/`, затем `npm run build:content`. Генерация обновляет `data/career/`.
- Additional или встроенная практика: соответствующий авторский файл в `data/practice/`.
- Экран или игровая механика: соответствующий файл `src/features/`; общие состояние и правила — `src/app/` и `src/core/`.
- Стили и картинки: `assets/`; конфигурация ключей/наград/Firebase — `src/config.js`.
- После изменения: обновить [журнал](Изменения.md), а при изменении устройства сервиса — [архитектуру](АРХИТЕКТУРА.md).

## Публикация

Текущий сайт: <https://languages-with-cases.github.io/pm-english/>. GitHub Pages публикует корень `main`; настройки публикации и дополнительный сервер менять для этой структуры не требуется. Все локальные URL относительные, скрипты загружаются с `defer` в явном порядке. Перед релизом проверяются новый кеш-идентификатор, Pages deployment и реальные выдаваемые файлы.

## Офлайн

Один раз откройте сайт с интернетом и дождитесь в **Progress → Settings → Offline learning** сообщения, что все пять треков сохранены. После этого открывайте тот же адрес (или ярлык на домашнем экране) без сети: задания и сохранение на устройстве доступны. Вход и синхронизация аккаунта требуют интернет. Первый запуск без предварительной загрузки невозможен. Данные сохраняются в том же браузере; не очищайте его хранилище.

После изменения production-файлов обязательно `npm run build:offline` и фиксация обновлённого `offline-assets.js`. Установленное обновление применяется после закрытия всех окон приложения. Для проверки: `npm run test:browser:offline` (этот набор сам запускает сервер). Backend, платный Firebase и разрешение на уведомления для офлайн-режима не нужны.
